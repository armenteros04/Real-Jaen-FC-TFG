1. Alcance y actores

El sistema se compone de dos subsistemas que ya están implementados:

  • Backend de procesamiento (main.py + módulos detection, tracking, role_refinement, calibration, analytics, utils.json_exporter): pipeline de visión artificial que, a partir de un vídeo de un partido, genera detecciones, tracking de jugadores/balón, roles de equipo, posiciones de campo homografiadas y analítica final (rendimiento, heatmaps, táctica, posesión).
  • Webapp (index.html): panel de control de un solo cliente (SPA) que permite lanzar el pipeline, monitorizar su ejecución en tiempo real, y explorar los resultados generados (plantilla y fichas de jugador, mapas de calor, análisis táctico, detecciones finales y jornadas de liga con sus clips).

Actores identificados:

Actor Descripción
Analista / Cuerpo técnico Usuario principal de la webapp: lanza análisis de vídeos y explora los resultados (rendimiento, táctica, heatmaps).
Administrador del sistema Perfil técnico que ejecuta el pipeline por CLI (python main.py --video ... --all) y gestiona los ficheros de vídeo/salida.
Servidor de análisis (server.py) Actor sistema: expone la API REST (/api/run, /api/status, /api/results, /api/jornadas/{n}/clips) y orquesta la ejecución del pipeline como proceso.
Pipeline de vídeo (main.py + módulos) Actor sistema: ejecuta detección, tracking, refinamiento de roles, calibración y analítica.

sequenceDiagram
    actor Analista

    end

    Main-->>API: proceso finalizado (código de salida)
    Webapp->>API: GET /api/status
    API-->>Webapp: {is_running: false, logs[]}
    Webapp->>Analista: "Análisis finalizado" + botón habilitado

stateDiagram-v2
    [*] --> Inactivo
    Inactivo --> Solicitado : POST /api/run(video, device)
    Solicitado --> Ejecutando : subprocess iniciado\n(main.py --video ... --all)
    Solicitado --> Inactivo : error al lanzar\n(vídeo no encontrado / backend caído)

    state Ejecutando {
        [*] --> Deteccion
        Deteccion --> Tracking
        Tracking --> RefinamientoRoles
        RefinamientoRoles --> Calibracion
        Calibracion --> Analitica
        Analitica --> [*]
    }

    Ejecutando --> Finalizado : proceso termina (exit 0)
    Ejecutando --> Error : proceso termina con error
    Finalizado --> Inactivo : GET /api/status confirma is_running=false
    Error --> Inactivo : usuario revisa logs y reintenta
